# Overview of Cellar Deployment

This section provides a guide for deploying cellar contracts and configuring their variations. The deployment process involves several steps and decisions regarding permutations and deployment, all of which are critical for strategists to understand.

In the following sections, we will cover the two major aspects of the cellar deployment process:

- **[Permutations](./strategists/deploy/cellar/permutations.html)**: This section details the various permutations available for cellar contracts, outlining the building blocks and providing examples of common contract combinations.

- **[How to Deploy a Cellar Contract](./strategists/deploy/cellar/deploy.html)**: This section explains the step-by-step instructions for deploying a specific permutation of a cellar contract, using the **[CellarWithMultiAssetDeposit](https://github.com/PeggyJV/cellar-contracts/blob/zaki/PeggyJYDeployments/script/Arbitrum/test/DeployTestMultiAssetDeposit.s.sol)** as an example.

By following this guide, strategists will have the tools and knowledge to successfully deploy cellar contracts and tailor them to specific strategies.

# Overview of Prerequisites

Before deploying a Cellar contract, strategists need to ensure that several key components and configurations are set up. This section outlines the necessary prerequisites, including adaptors, the deployer contract, environment setup, the price router, and the registry. 

In the following sections, we will cover the prerequisites for deploying a Cellar contract:

- **[Environment Setup](strategists/deploy/prerequisites/env-setup.html)**: The section also explains how to fill in the necessary environment variables and prepare for running deployment scripts.

- **[Deployer](strategists/deploy/prerequisites/deployer.html)**: This section covers how to set up the deployer contract, examples for deploying the deployer, and how to use it for managing cellar deployments.

- **[Registry](strategists/deploy/prerequisites/registry.html)**: This section covers the deployment and configuration of the registry, along with examples of integrating it with the price router and adaptors.

- **[Price Router](strategists/deploy/prerequisites/price-router.html)**: This section details the deployment and configuration of the price router.

- **[Adaptors](strategists/deploy/prerequisites/adaptors.html)**: Learn about the various adaptors available in the cellar contracts, which integrate Cellars with external DeFi protocols.

By ensuring these prerequisites are in place, strategists can smoothly deploy their cellar contracts.
